Remarks on hashed IDs (IRP5IT3aID, IRP5IT3aIDPersonalDetailID)
* 2009-2014: numbers
* 2015-2022: letters
We use 2015 entries

* IRP5IT3aID: Tax (individual tax returns) certificate ID assigned on firms, changes every year
* IRP5IT3aIDPersonalDetailID: Tax (individual tax returns) certificate ID assigned on jobs, changes every year
* A pair IRP5IT3aID-IRP5IT3aIDPersonalDetailID (= firm-job) pins down establishment location

Merge
1. [GeoLocationFile] (IRP5IT3aID, PAYERefno, IRP5IT3aIDPersonalDetailID, taxyear, suburb, LocMuni)
    ++merge using PAYERefno++ 
    [smallIRP] (taxrefno, PAYERefno)
    ==> 
    [GeoLF] 
    (taxrefno, IRP5IT3aID, PAYERefno, IRP5IT3aIDPersonalDetailID, taxyear, suburb, LocMuni)
2. [GeoLF] 
    ++merge using taxrefno, IRP5IT3aID, IRP5IT3aIDPersonalDetailID, taxyear++ 
    [irp5] 
    (taxrefno, IRP5IT3aID, IRP5IT3aIDPersonalDetailID, uid, taxyear, mainplace)
    ==> 
    [Irp5] 
    (taxrefno, IRP5IT3aID, IRP5IT3aIDPersonalDetailID, uid, taxyear, LocMun, mainplace)
